# TML Contractor Website

New website build based on the approved TML Contractor website plan and design direction.

## Setup
1. npm install
2. Create `.env.local` with `RESEND_API_KEY`, optional `CONTACT_TO=tevin@tmlcontractors.com`, and optional `CONTACT_FROM`.
3. npm run dev

The project portfolio intentionally contains no past TML project images. Add approved project assets later under `public/images` and update the Projects page.
